# Experiment 02 — Decision Trees & Ensemble Methods

**Datasets:** Iris (main) and Digits (optional tree demo)  
**Author:** Nabila Tajrin

---

## What this covers

1. **Decision Tree** on Iris — train/test split, predictions, misclassification rate, tree plot  
2. **Ensembles** on Iris — Bagging, AdaBoost, Random Forest, Gradient Boosting (+ SVM baseline)  
3. **Accuracy comparison** and optional **GridSearchCV** on Random Forest

## Run

```bash
cd 02-decision-trees-ensemble
pip install -r requirements.txt
python 01_decision_tree_iris.py
python 02_ensemble_methods_iris.py
```

Plots may open in a window; tree figure is also saved as `iris_decision_tree.png`.
